# Code of conduct

AppSleuth contributors and maintainers commit to a respectful, harassment-free community.

Be constructive, assume good intent while evaluating evidence, welcome people with different experience levels, and criticize ideas or code rather than individuals. Do not publish private filesystem information, security details, personal data, or identifying scan output without permission.

Harassment, discrimination, threats, sexualized conduct, sustained disruption, and retaliation are not acceptable in project spaces or when representing the project.

Maintainers may edit or remove harmful contributions and may temporarily or permanently restrict participation. Enforcement decisions should be proportionate, documented privately, and avoid exposing reporters.

Report conduct concerns privately to the repository owner through the contact method on their GitHub profile. For product vulnerabilities or data-safety issues, follow `SECURITY.md` instead.
